# Encounter test guide — lab 010

The start menu offers four isolated encounters and the existing highway run. Weapons autofire; existing PC/mobile cruise, fast, brake and boost controls apply to every choice. Retry preserves the selected encounter. The header, pause screen and results screen provide a route back to selection. Practice mode remains available in Tune. Enemy models and effects are temporary code-authored primitives.

All four encounters now receive pairs of normal red scouts, starting after 0.9 seconds and recurring every 4.8 seconds while the main objective remains active (up to four unpassed scouts alive). They enter from opposite sides, weave, and fire the normal three-shot aimed fan. They award ordinary kills but do not prevent a main-objective clear or create an endless reinforcement objective.

Attacking entities stage approximately 24–39 metres ahead in top-down mode instead of 64–110 metres. Every encounter shot, including scout fire, checks the actual camera projection: the full shooter body must fit within the playable view, with HUD/edge margins, for at least 0.7 seconds. Leaving the view resets that grace period. Interceptors only begin their warning while visible and restart aiming if they leave view before charging. This is a numeric projection gate, not an agent visual review.

Cruise matches the hauler when close behind, giving time to work across the locks. Fast/boost bypass following. Interceptors pace ahead while warning so maximum speed cannot consume the reaction window. Mines have swept proximity checks at boost speed; unarmed mines allow contact without damage.

Results distinguish **Encounter cleared**, **Escaped — objective incomplete**, and **Partial raid**. Remaining relevant mines/pickups must resolve before results. Combat rewards now strongly outweigh passing: Dart kills 250, Interceptors 750, layers 600, turrets 500; ordinary passes 10, clean Interceptor passes 75. Opening a lock pays 200; each cyan crate is explicitly labeled **SALVAGE +600** and shows a collection confirmation. A full clear awards a one-time 2,000-point bonus. Fast escape remains an option, not a completed objective.

These are isolated behavior tests, not yet mixed into the highway ramp schedule. The aim of this revision is to require responses to different targeting/movement behaviors rather than assume that higher projectile counts alone establish difficulty. The user evaluates that result.

Future piercing/spread weapons, ram shield, upgrade rewards, boost recharge pickups and generated 3D assets are not part of this version. Balance and visual readability are for the user's playtest. Agents perform only nonvisual validation, per `AGENTS.md`.
