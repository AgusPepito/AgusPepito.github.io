# UI direction concepts

Generated 2026-09-25 using the built-in image-generation tool. These are visual concepts, not screenshots of implemented UI. Three PNGs are saved in this directory: `menu-a-ivory-console.png`, `menu-b-orbital-minimal.png`, `menu-c-race-telemetry.png`.

Requested flow: a concise start screen with checkpoint selection, Race and Controls; no course-mode selector or explanatory paragraphs on the start screen. A dedicated controls screen should select PC or touch instructions based on the device, with a manual override for hybrid devices. Generated diagrams and labels are illustrative; implementation must use the actual controls and correct phase symbols. Final visual direction is awaiting the user's selection.

Performance UI now requires `dev=1`. With that flag, `perf=1` or `preload=all` opens the panel automatically, and F8 remains available. Without `dev=1`, the toggle stays hidden and panel activation, capture events, memory measurements and log saving are disabled.

## Prompt A

Use case: ui-mockup. Create a polished game UI concept presentation for VECTOR SHIFT, an orbital antigravity racer. One landscape image with three clearly separated interface mockups: a large desktop START SCREEN on the left occupying 60%, and two smaller clearly readable CONTROLS screens on the right, PC above and TOUCH below. These are design concepts, not an implementation screenshot. The actual game's world: ivory angular twin-engine racing ship with a cyan reactor, graphite and ivory panel racetrack in deep space, a blue planet on the right, distant sparse asteroids. Main menu must be beautifully simple: title VECTOR SHIFT, checkpoint selector with '01 / FIRST SHIFT', one large 'RACE' button, secondary 'CONTROLS' button, small fullscreen icon. No explanatory paragraphs, no course-mode selector, no driving-only option, no performance toggle, no fake currencies, no store, no extra menu options. PC controls: A/D or left/right arrows steer; Space jumps; W or Shift boosts; S brakes; 1 cyan circle / 2 amber triangle / 3 violet diamond switches phase. Mobile controls: two thumbpads, left pad sideways steers, up jumps, down brakes; right pad up boosts, left cyan / down amber / right violet selects phase. Controls screen automatically uses device-appropriate content with small PC / TOUCH tabs as an override. Use correct simple text, big legible buttons, deliberate typography and usable contrast. Phase accents cyan amber violet; warm ivory, graphite, brushed steel, restrained orange details; match the game world's materials. Control diagrams should feel visually clear rather than a wall of text. Direction A — IVORY CONSOLE. Premium physical motorsport instrumentation: warm ivory inset panels, graphite recessed controls, a few chamfered corners, slender seams and tiny mechanical fasteners. Main menu is an asymmetric ivory control console on left over a cinematic space racetrack and ivory ship on right. Bold condensed black typography, restrained cyan selected-state line. Controls are clean ivory schematic panels with graphite keycaps and two circular thumbpads. Not generic glowing blue sci-fi glass. Small top label 'A / IVORY CONSOLE' outside the mockup.
