# Vector Shift submission art inventory

This list describes the final racer's shipped content. Source studies and removed
music remain in Git history and documentation but are excluded from the release.

## Procedural 3D models

The 38 active standalone recipe modules are listed in
[`recipe-assets.json`](recipe-assets.json). Code constructs the ship, track,
obstacles, fixtures, asteroid prototypes and distant scenery through Three.js
geometry operations. See [the asset contract implementation](RECIPE_ASSETS.md).

## Generated images used in the game

All eight images below were generated with the built-in OpenAI image-generation
tool. The tool did not expose an exact model identifier. They are declared as
own art; they are not claimed as Atlas jam-credit outputs.

| `assets/space/planet-backdrop-r1.ktx2` | Forward planet backdrop | [Prompt](art/space/planet-backdrop-r1.md) |

| `assets/areas/dockyards-r1.webp` | Dockyards selection banner | [Prompt](art/ui/campaign-area-images-r1.md) |

KTX2 and WebP files are compressed derivatives of those generated images. Banner
art illustrates areas and is not represented as a gameplay screenshot. Generated
ship, track and interface references are documented under `docs/art/`; references
were used to guide procedural modelling and interface code, not imported as meshes.

## Music

- `assets/music/menu.mp3`: 90-second edited loop of the supplied `menuSong.mp3`.
- `assets/music/race-01.mp3`: supplied `output (2).mp3`, looped during races.

Creator, generator and usage-rights declarations are recorded in the
[music README](../public/assets/music/README.md). Those declarations are pending
the creator's confirmation; the files' presence is not proof of ownership.

## Code-generated effects and interface

Track surface grain, exhaust/glow sprites, trails, particles, projection effects,
phase symbols and interface styling are generated by game code. External raster
files used by the final game are limited to the eight images listed above.

## Software credits

The game uses Three.js and Supabase JavaScript libraries. Basis Universal
transcodes the KTX2 textures. The release includes the corresponding licence
notices under `licenses/` and `vendor/basis/LICENSE`. These are software
dependencies, not third-party 3D model assets.
